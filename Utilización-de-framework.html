4.2 ¿Cómo visualizar los resultados de la ejecución?

Una vez que la aplicación base está configurada, los resultados pueden visualizarse fácilmente en un navegador. Para ello, guarda los archivos HTML y JavaScript en la misma carpeta y carga el archivo HTML principal en el navegador.

Es importante inspeccionar posibles errores en la consola del navegador. Los navegadores modernos como Chrome y Firefox incluyen herramientas de desarrollo que permiten depurar JavaScript y verificar si hay problemas en el código AngularJS.

Para pruebas en tiempo real, se recomienda utilizar herramientas como Live Server, que actualizan automáticamente el navegador al guardar cambios en los archivos. Esto mejora el flujo de trabajo al permitir un desarrollo más rápido y fluido.

Con estos pasos, tendrás una aplicación base funcional y podrás visualizar cómo AngularJS gestiona los datos dinámicos y la interfaz. Este es el punto de partida para construir aplicaciones más complejas.
