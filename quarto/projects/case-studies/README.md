# Project case studies

Add one `.qmd` file per project in this folder. Give each file a descriptive,
lowercase filename; that filename becomes the published URL. Include `title`,
`date`, `description`, and optional `categories` in the YAML front matter.
The Quarto build publishes the case study and adds it to the projects listing.

Example:

```yaml
---
title: "Sensor acquisition firmware"
date: 2026-10-05
description: "A short project summary shown on the projects listing."
categories: [embedded-systems, firmware]
---
```
