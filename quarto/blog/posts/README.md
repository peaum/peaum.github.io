# Blog posts

Add one `.qmd` file per article in this folder. Include `title`, `date`,
`description`, `author`, and optional `categories` in its YAML front matter.
The Quarto build publishes the article and adds it to the blog listing.

Example:

```yaml
---
title: "A useful engineering note"
author: "Peace Umolu"
date: 2026-10-05
description: "A short summary shown on the blog listing."
categories: [embedded-systems, firmware]
---
```
