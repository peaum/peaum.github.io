2.1 ¿Se precisa instalación?

AngularJS no requiere instalación tradicional como otros frameworks. Puede utilizarse directamente desde una red de distribución de contenido (CDN) o descargarse localmente para integrarlo en un proyecto. La opción de usar la CDN permite acceder rápidamente al framework sin tener que almacenar archivos en el proyecto, lo que resulta ideal para proyectos pequeños o prototipos. Por otro lado, la descarga local es preferible en proyectos que necesitan mayor control sobre las dependencias o que no tienen acceso constante a internet.


2.2 Pasos para realizar la instalación

El primer paso para instalar AngularJS es descargar el archivo desde su página oficial o utilizar el enlace proporcionado por una CDN. Una vez obtenido el archivo, debe incluirse en el proyecto mediante la etiqueta <script> en el archivo HTML principal. Por ejemplo:

<script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>

Una vez integrado, es posible verificar que la instalación fue exitosa comprobando la versión instalada en la consola del navegador ejecutando el comando angular.version.


Versiones necesarias

AngularJS es compatible con navegadores modernos, lo que garantiza su funcionalidad en la mayoría de los entornos actuales. Sin embargo, es importante asegurarse de que la versión seleccionada cumpla con los requisitos específicos del proyecto, especialmente si se trabaja con sistemas legados.


Rutas para tener en cuenta

Al descargar localmente AngularJS, el archivo debe almacenarse en una ubicación accesible dentro del proyecto, como una carpeta js o lib. Además, si el proyecto utiliza un servidor, las rutas deben configurarse correctamente para que el archivo sea accesible desde el navegador.


Variables de entorno

Aunque AngularJS no requiere configuraciones de variables de entorno específicas, es común diferenciar entre entornos de desarrollo y producción. Por ejemplo, en desarrollo, los archivos pueden estar descomprimidos para facilitar la depuración, mientras que en producción se recomienda utilizar la versión comprimida para mejorar el rendimiento.


2.3 ¿Necesita base de datos?

AngularJS no incluye un sistema de gestión de bases de datos integrado, pero es altamente compatible con servicios REST, lo que lo hace ideal para trabajar con datos dinámicos desde un servidor backend. Puede integrarse fácilmente con plataformas como Firebase, MongoDB o cualquier otro sistema que proporcione una API RESTful. Estas integraciones permiten manejar datos dinámicos en tiempo real, una característica especialmente útil para aplicaciones modernas.
