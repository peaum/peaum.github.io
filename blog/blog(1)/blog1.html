Tiny project story

I connected a Cortex-M33 board to a sensor breakout and logged temperature values at fixed intervals.

Three immediate lessons:

  1. Clock setup and peripheral init order matter more than expected.
  2. Small buffer design choices can reduce dropped samples.
  3. Good logging makes debugging ten times easier.

Measurement model and formula

For this run, I use a moving average filter where \(x[n]\) is the latest raw ADC reading and \(N\) is the filter window:

\[ x_{avg}[n] = \frac{1}{N}\sum_{k=0}^{N-1} x[n-k] \]

When I estimate voltage from ADC counts for a 16-bit converter:

\[ V_{in} = \frac{ADC_{count}}{2^{16}-1} \cdot V_{ref} \]

These two equations make it easy to reason about noise reduction and conversion scaling before adding closed-loop control.

Example code chunk

# Simple moving average test for sensor readings
readings = [24.8, 25.1, 25.4, 26.0, 25.7, 25.5]
window = 3

ma = []
for i in range(len(readings) - window + 1):
    segment = readings[i:i + window]
    ma.append(round(sum(segment) / window, 2))

print("Moving averages:", ma)
