3.1 Cómo realizar una primera aproximación (“Hola Mundo”)

Para familiarizarse con AngularJS, el primer paso es crear una aplicación básica que muestre un mensaje sencillo, conocido como el ejemplo de “Hola Mundo” donde `Mundo` es una variable. A continuación, se describe el proceso para realizarlo:

1. Configuración básica del entorno

Paso 1: Crear un archivo HTML

Crea un archivo con extensión .html. Por ejemplo, index.html.

La característica ng-app establece el campo de acción de tu aplicación AngularJS. En este escenario, se trata de una aplicación bastante elemental sin un módulo.

Línea 11-12: Entrada de datos

El atributo ng-model enlaza dinámicamente el valor del cuadro de texto con la variable name. Todo lo que escribas en este campo se reflejará en tiempo real donde uses {{name}}.

Línea 15: Visualización dinámica

La expresión {{name}} evalúa el contenido de la variable name. Si el usuario escribe "Juan" en el cuadro de texto, el encabezado mostrará "Hola Juan" o si el usuario escribe "Mundo" mostrará "Hola Mundo".

4. Prueba de la aplicación

  1. Guarda el archivo con la estructura descrita.
  2. Abre el archivo en un navegador web.
  3. Escribe algo en el cuadro de texto. Verás que el encabezado cambia dinámicamente al saludo correspondiente.

5. ¿Qué has aprendido?

  • Cómo incluir AngularJS en un proyecto.
  • Uso del atributo ng-app para inicializar una aplicación.
  • Vinculación bidireccional de datos con ng-model.
  • Uso de expresiones como {{variable}} para mostrar datos dinámicamente.
