Explicación del Funcionamiento de
AngularJS

Leer más

5.1 ¿Actúa sobre páginas, ficheros, secciones…?

AngularJS opera directamente sobre el DOM (Document Object Model) de las páginas web. Esto significa que modifica y actualiza dinámicamente las vistas en función de los datos proporcionados en tiempo real, sin necesidad de recargar la página completa. Esta interacción dinámica es posible gracias a su capacidad de binding de datos bidireccional, que asegura que cualquier cambio en el modelo se refleje instantáneamente en la vista, y viceversa.

Por ejemplo, si un usuario interactúa con un formulario, los datos ingresados se actualizan automáticamente en el modelo, y cualquier cambio en el modelo afecta la interfaz de usuario.

5.2 ¿Cómo se editan/modifican los ficheros que actúan en el framework?

Los proyectos en AngularJS suelen organizarse en tres tipos principales de archivos: módulos, controladores y vistas. Los módulos agrupan los componentes de la aplicación, los controladores manejan la lógica y los datos, y las vistas representan la interfaz de usuario.

Para editar estos archivos, se recomienda utilizar herramientas de edición como Visual Studio Code, WebStorm o Sublime Text. Estas herramientas ofrecen características como resaltado de sintaxis, autocompletado y soporte para depuración, lo que facilita el desarrollo.

Es crucial configurar correctamente un entorno de desarrollo para maximizar la productividad. Esto incluye instalar extensiones o plugins específicos para AngularJS, configurar un servidor local (por ejemplo, Live Server) y establecer una estructura de carpetas lógica que permita un acceso fácil a los archivos del proyecto.

5.3 ¿Cómo se referencian los ficheros creados desde otras aplicaciones (si es el caso)?

Para editar estos archivos, se recomienda utilizar herramientas de edición como Visual Studio Code, WebStorm o Sublime Text. Estas herramientas ofrecen características como resaltado de sintaxis, autocompletado y soporte para depuración, lo que facilita el desarrollo.

Los archivos creados en AngularJS pueden integrarse fácilmente con bibliotecas externas y servicios. Por ejemplo, es común importar bibliotecas como jQuery para manipulación avanzada del DOM o usar Lodash para trabajar con estructuras de datos complejas. Esto se realiza mediante la inclusión de los archivos necesarios a través de etiquetas <script> en el HTML principal.

AngularJS también se conecta con APIs REST u otros servicios externos para obtener y enviar datos. Esto se logra utilizando $http o ng-resource, herramientas nativas del framework que simplifican las operaciones CRUD (crear, leer, actualizar, eliminar) en aplicaciones.

El uso de ng-resource es particularmente útil cuando se trabaja con datos remotos, ya que facilita la interacción con servicios web y gestiona automáticamente las operaciones asíncronas.
